¿La cita se confirma al enviar el formulario?+

No. El formulario envía una solicitud. La cita queda confirmada después de completar el depósito de $170 y de que Aurea Apartments reciba y verifique el pago.

¿Qué pasa con el depósito de $170?+

Si decides no continuar con el proceso de alquiler, los $170 serán reembolsados. Si continúas, se agregarán al depósito del primer mes de renta, según las condiciones indicadas por Aurea Apartments.

¿Se realiza algún cobro en esta página?+

No se procesa ningún pago aquí. Seleccionas un método de preferencia y, después de enviar la solicitud, te comunicas con el asesor para coordinar el pago.

¿Cómo conservo mi solicitud?+

Cuando se complete el envío de ambos correos, podrás guardar el documento usando «Guardar documento / PDF». También se enviará una copia de la solicitud a tu correo; revisa la carpeta de spam si no aparece.
